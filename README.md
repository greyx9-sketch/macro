# 저장소 안내

프로젝트를 **폴더 하나에 하나씩** 담는다. 각 폴더는 그 안에서 자기완결적이다 —
문서·`.gitignore`·`.gitattributes` 를 각자 갖고 있고, 명령도 그 폴더에서 실행한다.

| 폴더 | 무엇 | 상태 |
|---|---|---|
| [`시황/`](시황/) | 미국·한국 거시지표 22종 자동 수집 + 대시보드 → [사이트](https://greyx9-sketch.github.io/macro/) | 운영 중 |

## 루트에 있는 것

`.github/workflows/` 하나뿐이다. **GitHub 이 워크플로를 루트에서만 읽기 때문에**
이것만은 프로젝트 폴더 안으로 넣을 수 없다. 워크플로 파일 이름에 프로젝트를 드러내고,
안에서는 `working-directory:` 로 해당 폴더에 들어가서 돈다.

## 프로젝트를 추가할 때 알아야 할 것

**GitHub Pages 는 저장소당 사이트가 하나뿐이다.**

지금은 `시황/site` 를 통째로 배포해 `greyx9-sketch.github.io/macro/` 가 된다.
두 번째 프로젝트에도 웹페이지가 생기면 **한 저장소에서 둘 다 배포할 수 없다.** 선택지는 둘이다.

- **웹사이트가 있는 프로젝트는 별도 저장소로 만든다** — 정석이고 손이 덜 간다
- 배포 아티팩트를 합쳐 `/시황/`, `/다른것/` 처럼 하위 경로로 나눈다 —
  워크플로를 꽤 손봐야 하고, 각 사이트의 내부 링크가 전부 상대경로여야 한다

폴더로만 나누면 될 것 같지만 **Pages 에서 막힌다.** 두 번째 프로젝트를 넣기 전에 결정할 것.
