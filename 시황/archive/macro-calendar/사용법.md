# 사용법

## 지금 당장 쓰는 법 (PC)

`macro-calendar` 폴더에서 **`dev.cmd` 더블클릭** → 검은 창이 뜨고 서버가 켜집니다.

브라우저에서 **http://localhost:8788** 접속.

창을 닫으면 서버도 꺼집니다. 다시 보려면 또 더블클릭하면 됩니다.

## 폰에서 보는 법 (같은 와이파이)

**`폰에서보기.cmd` 더블클릭** → 창에 표시된 `http://192.168.x.x:8788` 주소를 폰 브라우저에 입력.

- PC 와 폰이 **같은 와이파이**여야 합니다
- 처음 실행하면 윈도우 방화벽 창이 뜹니다 → **[액세스 허용]**
- **PC 가 켜져 있어야만** 폰에서 보입니다

> 밖에서도 보고 알림까지 받으려면 Cloudflare 배포가 필요합니다. 아래 참고.

## 데이터 갱신

**`데이터채우기.cmd` 더블클릭** (서버가 켜져 있는 상태에서).

최신 지표 수치와 발표 일정을 받아옵니다. 1~3분 걸립니다.
배포 후에는 매일 새벽 자동으로 돌기 때문에 손댈 필요가 없습니다.

## 화면 보는 법

### 상단 4칸

미국·한국의 10Y-2Y 장단기 금리차와 기준금리. 옆의 작은 그래프는 최근 13개 구간 추이입니다.

- **10Y-2Y 가 마이너스** = 장단기 금리 역전. 경기 침체 신호로 읽는 지표입니다.

### 캘린더

- 칸 안의 **색 막대**가 발표 예정 지표입니다 — <span>파랑 = 미국</span>, <span>주황 = 한국</span>
- **흐리게 표시된 것**은 이미 발표가 끝난 항목
- **날짜를 누르면** 그날 발표 전체가 아래에서 올라옵니다 (시각, 기준월, 실제값, 직전값)
- `+2` 는 자리가 모자라 가려진 개수. 눌러서 확인하세요

### 버튼

| | |
|---|---|
| `‹` `›` | 월 이동 |
| `오늘` | 이번 달로 복귀 |
| `캘린더` / `리스트` | 리스트는 시간순으로 쭉 보는 방식. 수치 비교엔 이쪽이 편합니다 |
| `전체` / `🇺🇸` / `🇰🇷` | 국가 필터 |
| `전체` / `주요만` | `주요만` 은 ★★★ 지표만 (CPI·PCE·고용보고서·FOMC·금통위) |

### 숫자 읽기

리스트에서 이렇게 보입니다.

```
21:30  🇺🇸 소비자물가지수          2.57% ▼
       2026년 6월 · 근원 YoY ★★★   이전 2.82
```

앞의 큰 숫자가 이번 발표값, 아래가 직전 발표값입니다. ▼ 는 전보다 내려갔다는 뜻입니다.

> **예상치(컨센서스)는 없습니다.** 무료로 받을 수 있는 소스가 없어서, 실제값과 직전값
> 비교로 대신합니다.

## 텔레그램 알림

봇: **@greyx_macro_bot**

배포를 마친 뒤 봇에게 `/start` 를 보내면 등록됩니다. 그 뒤로는

- 주요 지표 발표 **30분 전** 예고
- 발표 **직후** 실제 수치 (직전값 대비 화살표 포함)
- 매일 **아침 7시** 그날 일정 요약

| 명령 | 동작 |
|---|---|
| `/today` | 오늘 일정 |
| `/next` | 다음 발표 5건 |
| `/major` | ★★★ 만 받기 |
| `/all` | 전체 받기 |
| `/stop` | 알림 끄기 |

## 밖에서도 쓰려면 (Cloudflare 배포)

PC 를 꺼도 폰에서 보이고, **알림이 실제로 오려면** 배포가 필요합니다. 무료입니다.

### 1단계 — 가입 (1분)

`dash.cloudflare.com` → Sign up → 이메일·비밀번호 입력 → 인증 메일 클릭.
카드 등록 없습니다. 요금제를 고르라고 하면 **Free** 를 선택하세요.

### 2단계 — `배포하기.cmd` 더블클릭

나머지는 전부 자동입니다.

1. 브라우저가 열립니다 → **[Allow]** 클릭 (Cloudflare 로그인)
2. D1 데이터베이스 생성
3. API 키를 Cloudflare 시크릿으로 등록
4. 배포
5. 텔레그램 웹훅 연결
6. 초기 데이터 채우기

3~5분 뒤 `https://macro-calendar.<계정>.workers.dev` 주소가 출력됩니다.

여러 번 실행해도 안전합니다. 코드를 고친 뒤 다시 돌리면 그대로 재배포됩니다.

### 3단계 — 폰에 설치

폰 브라우저로 그 주소를 열고 **공유 → 홈 화면에 추가**. 앱 아이콘처럼 쓸 수 있습니다.

### 4단계 — 알림 켜기

텔레그램에서 **@greyx_macro_bot** 에게 `/start`.

이때부터 PC 를 꺼도 발표 30분 전 예고, 발표 직후 수치, 아침 7시 요약이 옵니다.

## ISM PMI 만 예외

ISM 이 저작권을 이유로 데이터 공개를 막아둬서 어떤 무료 API 에도 없습니다.
**발표 일정은 캘린더에 정확히 뜨고 알림도 가지만, 숫자는 자동으로 안 채워집니다.**

넣고 싶으시면 발표 후 ISM 사이트에서 값을 확인해 직접 입력합니다. 자세한 명령은
[README.md](README.md) 의 "ISM PMI 수동 입력" 참고.

한국 PMI 도 같은 이유로 빠져 있습니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 브라우저에 아무것도 안 뜸 | `dev.cmd` 창이 켜져 있는지 확인 |
| 숫자가 다 비어 있음 | `데이터채우기.cmd` 실행 |
| 폰에서 접속 안 됨 | 같은 와이파이인지, 방화벽 허용했는지 확인 |
| 포트가 사용 중이라고 나옴 | 이전 창이 안 닫혔을 수 있습니다. 작업관리자에서 `node` 종료 |
