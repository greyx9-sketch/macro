## 그런데도 남긴 이유 — 지금 프로젝트에 없는 것 셋

1. **FRED `/release/dates` API 로 BLS·BEA 확정 공표일정** (`src/fred.js`) ← **이게 진짜 이유다**
2. 텔레그램 알림 (`src/telegram.js` · `src/notify.js` · `src/bot.js`)
3. PWA — 홈화면에 앱처럼 추가 (`public/manifest.json`)

### 1번을 다시 봐야 하는 이유

구버전 README 에 이렇게 적혀 있다:

> 미국 발표 일정은 **하드코딩하지 않습니다.** FRED 의 `/release/dates` API 가 BLS·BEA 의
> 확정 공표일정을 그대로 갖고 있어서 그대로 씁니다.

지금 프로젝트는 발표 예정일을 `estimatedNext` **추정**으로 다룬다.
그리고 `HANDOFF.md` §2-5 는 그 추정을 **믿으면 안 된다**는 결론에 이미 도달했다 —
ISM 은 발표일 표본이 0이라 가장 망가진 계열이 정확히 감지기의 사각지대였다.

**구버전은 그 문제를 애초에 겪지 않았다.** 공식 공표일정을 받아 썼기 때문이다.
정체 감지나 발표 예정일 표시를 손볼 일이 생기면 `src/fred.js` 를 먼저 읽어라.
